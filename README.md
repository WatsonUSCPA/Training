# 💪 筋トレ記録アプリ

自分用の筋トレ記録アプリです。サーバー不要で、ブラウザだけで動きます。
データは端末（ブラウザ）の `localStorage` に保存されます。

## 機能

- **⏱ タイマー**
  - ストップウォッチ（経過時間の計測）
  - インターバルタイマー（30秒〜3分のプリセット / 任意の秒数設定。終了時にビープ音）
- **📝 記録**
  - 部位を選ぶと、その部位で過去に追加した種目から選べる
  - 種目が無ければ「＋」で新規追加（部位そのものの追加も可能）
  - セットごとに重量(kg)・回数を入力（セットの追加・削除）
  - メモも残せる
- **📊 履歴 / 出力**
  - 記録を日付順で一覧表示、部位で絞り込み
  - **CSV出力**（Excelでそのまま開ける UTF-8 BOM 付き）

## 使い方

スマホ・PCどちらでもOKです。

### そのまま使う
`index.html` をブラウザで開くだけで使えます。
スマホでは「ホーム画面に追加」するとアプリのように起動できます。

### GitHub Pages で公開する（どの端末からも使える）
1. リポジトリの **Settings → Pages**
2. **Source** を `Deploy from a branch` にする
3. ブランチを選んで `/ (root)` を指定して保存
4. 表示されたURLにアクセス

## データについて
- データはブラウザごとに保存されます（別の端末・別のブラウザとは共有されません）。
- バックアップは「CSV出力」で行えます。
- ブラウザのデータを消去すると記録も消えるのでご注意ください。
